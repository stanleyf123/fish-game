# 悠游水族箱

純 HTML / Canvas 養魚遊戲。開啟 `index.html` 即可遊玩，或以 `python3 -m http.server 8080 --bind 127.0.0.1` 啟動預覽。

## 本次改善

- 海綠色水族館介面、玻璃面板、波光與手機版布局。
- 五段新手成就，完成後手動領獎，已領獎項不會重複發放。
- 魚兒吃到飼料後，七秒內繼續吃就累積連擊；每五次發放一次獎勵，上限每次十枚金幣。
- 一鍵收取水中金幣、飢餓提示、餵食愛心及遊戲說明。
- 使用原有 `yuyou-aquarium-v1` 存檔，載入舊版時自動補上成就資料；成就與領獎狀態一起保存。

## 驗證

`node tests/game.test.cjs`

涵蓋餵食連擊、任務重複領獎防護、存檔保存、舊存檔載入、收取金幣及重置。

正式服務由 feedfishs.com 的 Nginx 主機提供。發布 GitHub 原始碼與更新正式主機是兩個獨立步驟；正式更新後應核對網站內容與提交版本。
